# 0022. parity 하네스는 회귀 가드지 적정성 판정기가 아니다 — 탐지 개선 트랙 폐기

- 상태: 수락
- 날짜: 2026-07-10
- 관련: [0021](0021-parity-experiment-control-group.md)(하네스를 낳은 실험) · [0019](0019-freeze-heavy-lane-and-renderer.md)(동결)

## 맥락

[ADR 0021](0021-parity-experiment-control-group.md)의 parity 실험을 1차 실행했다(시나리오 1개, 팔당 3회).
세 축이 **성질이 다르게** 나왔다.

```
                        대조군(손-작성 루프)   처리군(docsherpa 생성 루프)
탐지 재현율                    67%                    50%
억제(필요 없는 문서 안 만듦)    3/3                    3/3
보존(사실인 문서 안 건드림)     3/3                    3/3
```

첫 반응은 *"탐지가 약하니 앵커를 명시적 체크리스트로 바꿔 재현율을 올리자"* 였다. **그 계획을 폐기한다.**
이유는 "탐지가 충분해서"가 아니라 **알 수 없어서**다.

### 실측 1 — n=3으로는 아무것도 말할 수 없다

Clopper–Pearson 95% 신뢰구간:

| 타깃 | 검출 | p̂ | 95% CI |
|---|---|---|---|
| 대조군 `SPEC.md` | 2/3 | 0.67 | **[0.10, 0.99]** |
| 처리군 `ADR-0020` | 1/3 | 0.33 | **[0.01, 0.91]** |

`p=0.6`을 `±0.15`로 추정하려면 **팔당·시나리오당 n≈41**. 앵커를 고치고 전후를 비교하려면 80회가
넘는 에이전트 실행이 필요하다. 그 비용을 치를 근거가 없다.

### 실측 2 — per-run 재현율은 애초에 틀린 지표다

`doc-reconcile`은 **매 세션 다시 발동한다.** 낡은 문서는 잡힐 때까지 후보로 남는다. 같은 앵커를
건드리는 변경이 반복되면 검출 확률은 누적된다. **루프는 탐지기가 아니라 샘플러다.**
per-run recall이 아니라 "몇 번의 관련 변경 안에 잡히는가"가 옳은 물음인데, 그것 역시 위의 n 문제로
실용적 표본에서 못 잰다.

### 실측 3 — 아레나는 실사용보다 불리하다(외적 타당도)

아레나의 에이전트는 **차가운 상태**로 diff 하나를 받는다. 실제 세션의 에이전트는 방금 자기가 그
코드를 썼고, 왜 그렇게 했는지 알고, 무엇을 읽었는지 기억한다. **50%는 하한일 가능성이 크다.**
아레나가 낸 탐지 수치를 실사용 적정성의 근거로 쓸 수 없다.

### 실측 4 — 억제·보존은 정반대 성질이다

둘은 **이진·희귀사건**이다. 6/6이었고, **한 번만 깨져도 즉시 안다.** 소표본으로 감시할 수 있고,
실제로 사용자를 아프게 하는 축도 이쪽이다(문서가 즉시 오염된다).

## 결정

**하네스의 사용 범위를 두 가지로 못 박는다.**

1. **억제·보존 = 회귀 가드.** 루프 산문을 고칠 때마다 돌린다. 위반 1건이면 퇴행이다. 소표본으로 충분.
2. **탐지 = 측정하지 않는다.** 수치를 내되 **의사결정에 쓰지 않는다.** `score.py`는 계속 재현율을
   출력하지만 그건 관찰용이다. 재현율이 오르내렸다고 산문을 바꾸지 마라.

**따라서 "앵커 체크리스트화 → 재현율 재측정 → 채택" 트랙을 폐기한다.** 측정할 수 없는 것을 목표로
삼으면, 좋아진 것 같다는 느낌으로 끝난다 — 이 프로젝트가 220커밋 동안 해 온 일이다.

**적정성은 실사용으로만 답한다** → [how-to/review-real-usage.md](../how-to/review-real-usage.md).

## 결과

- 3단계(앵커 개선)에 쓸 뻔한 80+ 에이전트 실행을 아낀다.
- 회고에서 볼 것이 명확해진다: **억제·보존 위반 = 즉시 조치 / 탐지 랭킹 = 작업 목록일 뿐.**
- 하네스가 더 자라지 않는다. 현재 프로덕션 **376줄**(`arena.py` 183 + `score.py` 193), 측정 대상
  (`doc-reconcile/SKILL.md`)은 **136줄**이다. **도구가 대상의 2.8배**이고, 이 비율 자체가
  [0019](0019-freeze-heavy-lane-and-renderer.md)가 경고한 병의 모양이다(렌더러 562 vs 오라클 312).
  하네스도 동결 대상에 준한다 — 확장하려면 이 ADR을 supersede하라.

## 수용한 트레이드오프

루프가 낡은 문서를 **놓쳐도 우리는 그 사실을 체계적으로 알 수 없다.** 오른쪽 절단(right-censoring):
아무도 눈치 못 챈 stale 문서는 어떤 지표에도 안 잡힌다.

완화책은 하나뿐이고, 자동화하지 않는다: **가끔(분기 1회쯤) 차가운 에이전트에게 "낡은 문서를 찾아라"고
시켜 정답지를 새로 만든다.** 비싸므로 자주 하지 않는다. 이 한계를 감수하는 이유는, 감수하지 않으면
측정 인프라가 제품보다 커지기 때문이다.

## 검증

- 신뢰구간·필요 표본수는 재현 가능: `n=3, k=2` Clopper–Pearson, 정규근사 `n ≈ 1.96²·p(1-p)/e²`.
- 억제·보존이 실제로 희귀사건임은 1차 실험 6/6·6/6이 뒷받침한다(반증되면 이 ADR을 supersede하라).
