# 0001. 단일-플러그인 repo + marketplace.json self-host

- 상태: 수락
- 날짜: 2026-07-04

## 맥락

플러그인을 어떻게 배포·호스팅할지 정해야 했다. 마켓플레이스 정의가 필요한데, 이를 별도 repo로
분리(모노레포)할지 같은 repo에 둘지가 쟁점.

## 결정

단일-플러그인 repo에 `marketplace.json`을 self-host 한다 — 마켓플레이스가 같은 repo에
`source:"./"`로 공존한다.

## 결과

- 좋음: 마켓플레이스가 같은 repo에 공존해 배포 구조가 단순하다.
- 거부한 대안: 멀티-플러그인 모노레포 — 현재 플러그인이 하나뿐이라 YAGNI.
