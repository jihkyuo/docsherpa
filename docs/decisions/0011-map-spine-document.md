# 0011. 맵 중추 문서 (routing·index를 진입파일 밖으로)

- 상태: 수락
- 날짜: 2026-07-06

## 맥락

D8은 섹션 계약을 언어-불문 HTML 마커로 삼되, 그 마커가 **진입 라우터(AGENTS.md) 헤딩 줄에
인라인**으로 산다고 암묵 전제했다. 그러나 AGENTS.md는 ①바쁜 파일(중추가 휩쓸림) ②부재 가능
(CLAUDE-only repo) ③"얇은 진입 라우터" 원칙과 상충한다. 초기엔 "맵을 빼면 gate 도달성 BFS가
붕괴한다"는 근거로 인라인을 고수했으나(N8), 실측 결과 **일반 마크다운 링크면 gate가 재귀로 따라가
통과**함이 드러나 그 근거가 거짓으로 판명됐다.

## 결정

routing·index 마커를 진입파일 밖 **중립명 맵 중추 문서 `docs/_map.md`** 로 이전한다. 진입파일엔
맵으로 가는 **마크다운 링크 한 줄 + `<!-- docsherpa:map -->` 마커**만 남긴다. gate는 그 링크를
재귀 BFS로 따라가 맵에 도달하고, `--require-markers`의 home locator는 도달 가능한 문서 중 두 마커를
**헤딩 줄에** 함께 가진 파일(=맵)을 **정확히 1개** home으로 요구한다. 기존 인라인 repo는
`scaffold.migrate_inline_to_map`이 **비파괴로**(내용 verbatim 이동·링크 URL만 재작성) 맵으로
이관하며, `content_oracle` 미분류 0으로 내용 소실 0을 기계 증명한다. (N11, redesign plan §3.8.)

## 결과

- 좋음: 루트 footprint가 "2마커+~30줄"→"1마커+1링크"로 감소. AGENTS.md가 바쁘거나 CLAUDE-only여도
  중추가 독립. docsherpa 자신도 이 구조로 마이그레이션(dogfood).
- D8과 화해: 마커는 여전히 언어-불문 HTML 마커다 — **위치만** 인라인→맵으로 이동(D8 폐기 아님).
- N8(인라인 유지) supersede: 인라인 강제 근거(gate BFS 붕괴)가 실측으로 거짓 판명돼 뒤집음.
- 거부한 대안: 인라인 유지(SPOF 없음이 장점이나 바쁜파일·부재·얇은라우터 원칙에 밀림) · 전용
  맵 도구+커스텀 포맷+주석 포인터(rev4-5 묶음, 과분할로 폐기).
- 도달성: content_oracle(내용 소실 0)·gate(도달성 100%)가 이 이전의 안전선. 맵 링크가 지워져
  조용히 orphan 될 위험은 후속(sidecar home 기록·자가치유)에서 강화 예정.
