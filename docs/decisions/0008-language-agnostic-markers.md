# 0008. 섹션명 계약 = 언어-불문 마커

- 상태: 수락
- 날짜: 2026-07-04

## 맥락

doc-reconcile이 라우팅/인덱스 섹션을 **헤딩 문자열**로 찾으면, 소비자가 AGENTS.md를 번역하는
순간 한국어 헤딩이 무효화되어 앵커가 전멸한다(codex·architect 둘 다 지적).

## 결정

섹션명 계약을 **언어-불문 HTML 마커** `<!-- docsherpa:routing -->` · `<!-- docsherpa:index -->`로
삼는다. 한국어 헤딩 문자열 의존을 폐기한다.

## 결과

- 좋음: 헤딩이 번역·재작성돼도 마커로 섹션을 찾으므로 불변이다.
- 거부한 대안: 헤딩 문자열 매칭 — 번역·wording 변경에 취약.
