# 0003. 독푸딩 — 플러그인 = 단일 원본

- 상태: 수락
- 날짜: 2026-07-04

## 맥락

doc-reconcile이 원래 second-brain에 살았다. 이를 플러그인으로 뽑아낸 뒤, 두 곳(원본 + 플러그인)을
어떻게 유지할지가 문제였다.

## 결정

**독푸딩** — 플러그인을 단일 원본으로 삼고, second-brain을 첫 고객으로 재스캐폴드한다.
두 벌을 유지하지 않는다.

## 결과

- 좋음: drift 0(원본이 하나) + 포트폴리오 서사(자기 도구를 자기가 씀).
- 거부한 대안: 포크 — 두 원본이 시간이 지나며 drift 한다.
