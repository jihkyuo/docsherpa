# 0004. doc-reconcile = 한 파일, 두 쓰임

- 상태: 수락
- 날짜: 2026-07-04

## 맥락

doc-reconcile을 공개용으로 일반화하면 second-brain 특화 앵커(구체적 힌트)를 잃는다. 이는
[0002](0002-committed-scaffold-in-target.md)(커밋 스캐폴드)·[0003](0003-dogfooding-single-source.md)(단일 원본)와 화해해야 한다.

## 결정

**한 파일, 두 쓰임** — 척추(방법론)와 범용 앵커를 담은 하나를 정본으로 두고, 스캐폴드될 때
그 프로젝트에 맞게 앵커를 특화한다.

## 결과

- 좋음: 유지보수가 단순(한 파일)하면서 [0002]·[0003]과 화해된다.
- 거부한 대안: 앵커 삭제 — 방법론이 빈약해진다.
