# PRD: 비파괴 문서 마이그레이션

> 제품 요구(왜 만드나·누구에게·성공/수용 기준). 설계·근거는 [ADR](../decisions/README.md)·[DESIGN](../DESIGN.md), 무엇을·어떻게는 spec에서.

## 왜 만드나 (문제)

레포 문서는 시간이 지나면 중구난방이 된다. 하지만 재구조화는 내용·앵커 소실 위험이 커서
아무도 손대지 않는다 — "고치다 뭔가 잃을까 봐". 그래서 문서 부채는 방치되고, 신규 진입자는
어디를 봐야 할지 모른다.

## 누구에게 (대상)

문서가 뒤죽박죽이지만, 각자 갈고닦은 **중요한 앵커·지점을 잃고 싶지 않은** 레포 소유자.
docsherpa는 주인이 아니라 **보조**다.

## 무엇을 (범위)

중구난방 문서 → 베스트프랙티스 구조(얇은 진입 라우터 + 도달성 불변식)로 마이그레이션한다.
내용은 그대로 두고 **구조만** 옮긴다.

## 성공/수용 기준

- **내용 소실 0** — `content_oracle` 미분류 세그먼트가 하나라도 있으면 FAIL.
- **도달성 100%** — `gate` broken=0 · orphan=0.
- **사용자 고유 앵커 보존** — §7.5 앵커 재특화로 사용자 리터럴 앵커를 살린다.
- **기존 문서 안 덮음** — scaffold는 없는 것만 생성·append-only.

## 비목표

- 문서 내용 재작성·요약 (구조만 옮김, 내용은 그대로).
- 자동 파일 이동 (이동=내용 위험 → 승인 필요, doc-reconcile은 옮기지 않음).
